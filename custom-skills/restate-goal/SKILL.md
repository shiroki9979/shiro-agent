# restate-goal

> 建立日期：2026-10-04
> 最後更新：2026-10-07

以不同措辭整理使用者目標、待解問題與影響實作方向的歧義。

## 規則

- 明確要求僅複述、確認理解或單獨呼叫本技能時，完成複述後結束，保持檔案不變。
- 實作任務中因關鍵歧義採用本技能時，只詢問會改變實作方向的問題；沿用已提供的答案，歧義解除後繼續原本已授權的任務。
- 使用不同措辭，不逐字重複原話。
- 分兩段輸出：**目標**（預期結果）、**問題**（待解事項與現況阻礙）。
- 推測明確標示為假設；仍有關鍵歧義時，最後列出待確認問題。

補充脈絡：$ARGUMENTS
