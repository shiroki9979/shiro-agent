# restate-goal

用你自己的話重新描述你認為我的目標是什麼，以及我試圖解決的問題是什麼。

## 規則

- 只複述與確認，不開始實作、不修改檔案。
- 使用自己的措辭，不逐字重複我的原話。
- 分兩段輸出：**目標**（我想達成什麼）、**問題**（我試圖解決什麼、現況為何受阻）。
- 若有推測成分，明確標示為假設；若有關鍵歧義，最後列出需我確認的問題。

補充脈絡：$ARGUMENTS
